プライバシーポリシー

対象アプリ: YouTube 後で見る（自動）（個人用ツール）

1. 取得する情報

利用者本人が Google アカウントで許可した場合に限り、YouTube Data API を通じて次の情報を取得します。

  • 本人の登録チャンネルの一覧
  • それらのチャンネルの新着動画の公開情報（タイトル・公開日時・動画 ID 等）
  • 本人の再生リストの情報

2. 利用目的

取得した情報は、本人の非公開再生リストに新着動画を追加する目的にのみ使用します。他の目的には一切使用しません。

3. 保存場所

アクセストークンおよびリフレッシュトークンは、利用者本人のパソコン内のみに保存されます。外部のサーバーへ送信・保管することはありません。取得した動画情報も、重複追加を防ぐための記録として本人のパソコン内にのみ保存されます。

4. 第三者提供

取得した情報を第三者へ提供・販売・譲渡することはありません。広告・分析・機械学習の学習データなど、いかなる二次利用も行いません。

5. 限定的な使用（Limited Use）

本アプリによる Google ユーザーデータの取得・利用は、Google API サービスのユーザーデータに関するポリシー（限定的な使用の要件を含む）に準拠します。

6. 権限の取り消し・データの削除

Google アカウントの サードパーティ製アプリとサービス からいつでもアクセス権を取り消せます。取り消した時点で本アプリは一切の情報を取得できなくなります。パソコン内に保存されたトークン・記録は、該当ファイルを削除することで消去できます。
